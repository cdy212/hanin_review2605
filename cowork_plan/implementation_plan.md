# 구현 플랜

AI 기반 PMO 협업 화면을 운영하기 위해 필요한 작업 계획입니다.

## 1. 입력 데이터 정의

- 회의록 원문
- 결정 사항
- 미결 사항
- TODO
- GitHub Issue / PR / Commit 요약
- QA 상태
- 리스크 목록
- 최종 의사결정 필요사항

## 2. 화면 구성

- 최종 의사결정자 Dashboard
- 현재 진행률 KPI
- 의사결정 필요사항
- 리스크 및 병목
- 회의록 요약 결과
- GitHub 작업 상태
- 사람이 해야 하는 작업
- 산출물 링크

## 3. 데이터 처리 규칙

- 회의록은 결정 / 미결 / TODO / 리스크로 분해
- GitHub 상태는 Issue / PR / QA 기준으로 요약
- 진척률은 완료 TODO, PR Merge, QA 상태를 종합
- 3일 이상 상태 변화 없는 항목은 리스크 후보
- 대표 승인 없이는 범위 변경 확정 금지

## 4. 사람 역할

- 최종 결정
- 우선순위 결정
- 일정 조정 승인
- 운영 데이터 입력
- 디자인 시안 승인
- QA 최종 확인

## 5. AI 역할

- 요약
- 분류
- TODO 초안 생성
- 리스크 탐지
- 진척률 분석
- Dashboard 문안 생성

## 6. 1차 산출물

- `index.html`: 의사결정 압축형 PMO 화면
- `styles.css`: 화면 스타일
- `app.js`: 샘플 데이터 렌더링
- `human_actions.md`: 사람이 해야 하는 작업
- `workflow.md`: 전체 운영 흐름
- `pmo_master_prompt.md`: AI PMO 프롬프트

## 7. 이후 확장안

- GitHub API 연동
- 회의록 입력 폼
- TODO 자동 Issue 생성
- 의사결정 항목 승인 로그
- 담당자별 진행률 자동 집계
- 리스크 알림
