## 선택된 방식: C안

- **A안** (기각): `cowork_plan/index.html` 업그레이드 — 기존 PMO 내부 도구 위치 유지
- **B안** (기각): 루트 `index.html` 하단에 PMO 현황판 통합 — 브리핑 페이지와 혼재
- **C안** (채택): 루트 폴더에 `dashboard.html` 신규 생성 — 독립적인 최종 대시보드

### C안 선택 이유

- 브리핑(`index.html`)과 PMO 대시보드(`dashboard.html`)를 명확히 분리
- 서버 배포 시 URL 분기 용이 (`/` vs `/dashboard`)
- 기존 파일 영향 없음

```

```

### 섹션 구성 (7단계 매핑)

| 섹션 | 대응 단계 | 내용 |
|---|---|---|
| 사이클 인디케이터 | Step 1–7 | 현재 어느 단계 진행 중인지 시각화 |
| Executive KPI | Step 7 | 전체 진행률, 의사결정 건수, 리스크 건수, 다음 리뷰 |
| 의사결정 필요사항 | Step 7 | 승인자가 판단해야 할 항목 (Priority H/M) |
| 회의록 요약 결과 | Step 1–2 | AI가 정리한 결정/미결/리스크 |
| TODO 목록 | Step 3 | P0~P3 우선순위 분류 |
| GitHub 작업 상태 | Step 4–5 | Issue/PR 현황, 병목 |
| 진척률 분석 | Step 6 | 이번 사이클 기준 진행률 변화 |
| 사람이 해야 할 일 | — | 역할별 액션 요약 |
