2. 회원가입 정보 수집 범위
이름			한인회 회원 확인용
휴대폰 번호		본인 확인, 연락
이메일			로그인/공지 수신
생년월일		회원 통계, 연령대 확인
주소			대만 내 거주 지역 확인
거주 지역		타이베이, 신베이, 타이중 등 지역 기반 서비스
직업/소속		한인 네트워크 기능 확장 가능
마케팅/공지 수신 동의	개인정보 이슈 방지

회원가입에서 너무 많은 정보를 필수로 받으면 사용자가 가입을 포기 가능 
1 단계: 간편 가입 - 카카오 / Google / Apple / 이메일
2단계: 기본 정보 입력 - 이름, 휴대폰번호, 이메일, 거주 지역
3단계: 선택 정보 입력 - 생년월일, 상세 주소, 직업/소속
4단계: 약관 동의 - 서비스 이용약관, 개인정보 수집 동의, 커뮤니티 운영정책 동의
