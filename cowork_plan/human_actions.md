# 사람이 직접 해야 하는 작업

이 문서는 AI가 자동 처리할 수 없는 사람의 판단, 승인, 운영 입력 업무만 분리한 목록입니다.

## 최종 의사결정자

- 1차 배포에 포함할 메인 서비스 항목 결정
- 일정 지연 또는 범위 축소가 필요한 경우 최종 판단
- 디자인 시안 최종 승인
- 정보 고급화 항목의 운영 책임 범위 결정
- 외부 출처 기반 콘텐츠의 공개 가능 여부 결정

## 승인자 / 대표

- 디자인 시안 확인
- 조정 피드백 전달
- 개발팀 재요청 사항 승인
- 최종 리뷰 일정 확정
- 의사결정 필요 항목의 우선순위 지정

## 개발팀

- 승인된 디자인 시안 반영
- GitHub Issue 기준으로 작업 단위 분리
- PR 생성 및 상태 업데이트
- QA 전 주요 메뉴 접근성 확인
- 링크, 참고자료, 데이터 표시 오류 수정

## 운영팀

- 공지, 뉴스, 지도, 업체 정보, 역사 콘텐츠 등록
- 콘텐츠 출처 정리
- 검증 필요 정보와 공개 가능 정보를 분리
- 운영 정책 초안 작성
- 배포 후 사용자 피드백 수집

## QA / 리뷰 담당

- 모바일/데스크톱 화면 확인
- 주요 메뉴 접근 동선 확인
- 새 탭 링크 및 참고자료 링크 확인
- 데이터 수치 표시 오류 확인
- 배포 전 승인 체크리스트 작성

## AI PMO가 보조하는 일

- 회의록 요약
- TODO 초안 생성
- GitHub 상태 분석
- 리스크 탐지
- Executive Dashboard 문안 생성

AI PMO는 최종 결정을 대신하지 않습니다.
