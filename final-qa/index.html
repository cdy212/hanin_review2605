PART 1. 접속 및 권한 체계

ROLE MANAGEMENT
업무 플로우: 운영자 접속 (https://koreans.tw/admin/index.html) → 권한 검증 (ROLE_ADMIN) → 통합 콘솔 진입 | 제휴업체 접속 (https://koreans.tw/login) → ROLE_PARTNER 기능 수행
관리자 콘솔 (A): https://koreans.tw/admin/index.html
사용자 로그인 (F): https://koreans.tw/login
역할 코드 표시 명칭 허용 기능 및 접근 권한
ROLE_ADMIN 최고 관리자 관리자 콘솔 전체 (배너, 심사, 회원, 쿠폰, 게시글, 제재 관리)
ROLE_PARTNER 제휴업체 한인맵 매장 등록/수정, 자체 매장 쿠폰 발행/관리
ROLE_REGULAR 정회원 일반 기능 + 제휴 쿠폰 다운로드 및 매장 현장 사용, 정회원 전용 커뮤니티
ROLE_USER 일반회원 기본 커뮤니티 열람/작성, 정회원 및 제휴업체 승인 신청
운영자 로그인 화면
사용자 로그인 화면

PART 2. 메인 CMS 관리 (TOP 배너)

CONTENT DISPLAY
업무 플로우: [https://koreans.tw/admin/index.html?section=mainContent] → TOP 배너 선택 → 제목/링크/순서/이미지 입력 → [저장] → [https://koreans.tw/main] 새로고침하여 즉시 노출 검증
관리자 CMS (A): https://koreans.tw/admin/index.html?section=mainContent
노출 확인 (F): https://koreans.tw/main
구분 최대 활성 수 정렬 규칙 권장 규격 및 비고
TOP 배너 최대 5건 순서 오름차순 (동일 순서 시 최신 등록일 우선) 1200 x 600 px (2:1 비율), 제목, 설명, 링크, 버튼명 필수
운영자 CMS 대시보드 화면
사용자 메인 화면 노출 결과

PART 3. 멤버십 심사 관리 (정회원 & 제휴업체 승인)

MEMBERSHIP AUDIT
업무 플로우: [https://koreans.tw/membership 신청] → [https://koreans.tw/admin/index.html?section=membership 대기 목록 조회] → 첨부 증빙/사업자 서류 검토 → [승인(apply) / 반려(reject)] → 사용자 재로그인 시 권한 자동 반영
관리자 심사 (A): https://koreans.tw/admin/index.html?section=membership
사용자 신청/상태 (F): https://koreans.tw/membership
상태 코드 한글 상태명 운영자 처리 내용 및 시스템 반영
request 승인 대기 신규 신청 상태. 운영자의 서류 검토 대기
apply 승인 완료 REGULAR: role_id 3, PARTNER: role_id 4 부여. 사용자 재로그인 시 즉시 활성화
reject 반려 처리 반려 사유 필수 입력. 사용자 화면에 사유 안내 및 수정 후 재신청 가능
cancel 신청 취소 사용자 자진 취소 또는 권한 회수 처리 상태
관리자 멤버십 심사 관리 화면
사용자 멤버십 신청 현황 화면

PART 6. 쿠폰 발행 및 매장 현장 PIN 결제

COUPON & POS AUTH
업무 플로우: [쿠폰 생성(https://koreans.tw/coupon/manage/create)] → [정회원 다운로드(https://koreans.tw/coupon)] → [내 보관함 확인(https://koreans.tw/coupon/my)] → [매장 방문 제시] → [직원 PIN 비밀번호 입력] → 즉시 차감 및 사용완료 전환
관리자 쿠폰 (A): https://koreans.tw/admin/index.html?section=coupons
쿠폰 다운로드 (F): https://koreans.tw/coupon
내 쿠폰함 (F): https://koreans.tw/coupon/my
쿠폰 유형 대상 회원 수량 관리 및 사용 규칙

PERSONAL 지정된 특정 회원 관리자가 지정한 타깃 사용자에게만 개별 지급
매장 현장 PIN 인증 팝업

PART 9. 불량 회원 정지 및 소명서 심사

SANCTIONS & APPEAL
업무 플로우: 부정 이용 / 규정 위반 적발 → [https://koreans.tw/admin/index.html?section=sanctions] 제재 등록(정지 기간/사유) → 사용자 로그인 시 차단 안내(https://koreans.tw/block) 강제 이동 → 사용자 소명서 제출 → [https://koreans.tw/admin/index.html?section=sanctionCertificate] 소명서 검토 후 인용 시 제재 즉시 해제
제재 관리 (A): https://koreans.tw/admin/index.html?section=sanctions
소명서 검토 (A): https://koreans.tw/admin/index.html?section=sanctionCertificate
사용자 차단 화면 (F): https://koreans.tw/block
구분 처리 주체 상세 절차 및 시스템 반영
제재 등록 운영자 대상 회원 선택 후 정지 사유 및 일수(또는 영구) 지정. 저장 시 해당 계정은 즉시 세션 차단
차단 안내 시스템 제재된 계정 로그인 시 일반 화면 진입 불가 및 https://koreans.tw/block으로 강제 리다이렉트
소명서 제출 사용자 차단 화면에서 소명 사유 및 해명 증빙 자료 작성 후 제출
소명서 심사 운영자 제출된 소명서 검토 후 [승인] 시 제재 해제 및 정상 계정 복원, [기각] 시 제재 상태 유지
관리자 제재 및 회원 관리 콘솔
사용자 계정 상태 화면
