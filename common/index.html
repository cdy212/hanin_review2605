Step 1 — DB 선택 & 쿼리 복사
DB를 선택하면 컬럼 + FK 관계를 한 번에 조회하는 통합 쿼리가 표시됩니다.
⚡ 통합 조회 쿼리 (컬럼 + FK 관계 한 번에) 


        

          📌 사용법

          1️⃣ 위 쿼리 복사 → DB 도구(DBeaver / SSMS / SQL*Plus)에서 실행

          2️⃣ 결과를 JSON으로 내보내기 (DBeaver: 결과 우클릭 → "Copy as JSON")

          3️⃣ 다음 단계에서 붙여넣기 → ERD 자동 생성 완료!
