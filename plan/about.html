AutoERD 소개

SQL 한 줄이면
ERD가 완성됩니다

AutoERD는 SQL DDL(CREATE TABLE)을 붙여넣으면 즉시 인터랙티브 ERD 다이어그램을 생성하는 완전 무료 온라인 도구입니다. 설치 없이, 회원가입 없이, 지금 바로 사용할 수 있습니다.

왜 만들었나요?

데이터베이스 설계 작업을 할 때마다 ERD 도구를 찾아 설치하고, 계정을 만들고, 테이블을 하나씩 드래그하는 반복 작업이 번거로웠습니다. 이미 작성된 SQL DDL이 있는데 왜 ERD를 처음부터 그려야 할까요?

AutoERD는 이 문제를 해결하기 위해 만들어졌습니다. CREATE TABLE SQL을 붙여넣으면 FK 관계를 자동으로 감지하고, 인터랙티브 ERD 다이어그램을 즉시 생성합니다. PNG나 SVG로 내보내기도 가능합니다.

주요 기능
⚡

즉시 ERD 생성

SQL을 붙여넣고 버튼 하나로 인터랙티브 ERD 다이어그램을 즉시 생성합니다.

🔗

FK 관계 자동 감지

FOREIGN KEY 및 REFERENCES 구문을 자동으로 파싱해 관계선을 그립니다.

🗂️

그룹 자동 분류

테이블을 비즈니스 도메인별로 자동 분류해 복잡한 스키마도 한눈에 파악합니다.

🖱️

드래그 & 줌

테이블을 자유롭게 드래그하고, 마우스 휠로 확대/축소할 수 있습니다.

📥

PNG / SVG 내보내기

완성된 ERD를 PNG 이미지 또는 SVG 벡터 파일로 즉시 다운로드합니다.

🛡️

프라이버시 보호

입력한 SQL은 브라우저에서만 처리됩니다. 서버에 저장되지 않습니다.

지원 데이터베이스

다음 데이터베이스의 DDL 문법을 지원합니다.

MySQL PostgreSQL MariaDB

PRIMARY KEY, FOREIGN KEY, UNIQUE KEY, NOT NULL, 복합 PK/FK, 스키마명 포함 테이블, 인라인 REFERENCES 등 다양한 DDL 문법 패턴을 파싱합니다.

기술 스택

AutoERD는 서버가 없는 완전한 정적 사이트입니다. 모든 처리는 브라우저에서 이루어집니다.

순수 HTML / CSS / JavaScript Cloudflare Pages 배포 백엔드 없음 (Serverless) Google Fonts (Inter, JetBrains Mono)
자주 묻는 질문
정말 무료인가요? 숨겨진 비용이 있나요?
완전히 무료입니다. 회원가입도 필요 없습니다. 서비스는 광고로 운영됩니다. 광고를 제거하고 싶다면 브라우저 광고 차단 확장 프로그램을 사용하세요.
입력한 SQL이 서버에 저장되나요?
아니요. AutoERD는 서버 없이 동작하는 순수 클라이언트 사이드 도구입니다. 입력한 SQL DDL은 브라우저에서만 처리되며, 외부 서버로 전송되거나 저장되지 않습니다.
어떤 SQL 문법을 지원하나요?
CREATE TABLE 구문을 기반으로 MySQL, PostgreSQL, MariaDB의 대부분의 DDL 패턴을 지원합니다. PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, 복합 PK/FK, 스키마명 포함 테이블명 등을 파싱합니다.
내 DB에서 DDL을 어떻게 추출하나요?
메인 화면 하단의 "DB에서 DDL 추출하는 방법 보기"를 클릭하면 MySQL, MariaDB, PostgreSQL 별 추출 명령어를 확인할 수 있습니다.
모바일에서도 사용할 수 있나요?
네, 모바일 브라우저에서도 사용 가능합니다. 단, 복잡한 ERD는 넓은 화면에서 더 편리하게 작업할 수 있습니다.
