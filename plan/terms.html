이용약관

시행일: 2026-05-21

본 약관은 AutoERD(이하 "서비스")의 이용에 관한 기본 사항을 규정합니다. 서비스를 이용함으로써 본 약관에 동의한 것으로 간주합니다.

서비스 목적

AutoERD는 사용자가 입력한 SQL DDL(CREATE TABLE 구문)을 기반으로 ERD 다이어그램을 생성하는 무료 온라인 도구입니다. 회원가입 없이 즉시 사용 가능합니다.

사용자 책임

사용자는 본인이 입력하는 SQL DDL의 권한과 보안 책임을 가집니다. 다음 항목을 입력하지 않도록 주의하세요:

  • 데이터베이스 비밀번호 또는 접속 문자열(Connection String)
  • 실제 고객의 개인정보가 포함된 데이터
  • 기밀 비즈니스 정보

ERD 생성에는 CREATE TABLE 구조(스키마)만 필요합니다.

서비스 제공 범위

서비스는 현재 상태 그대로 제공되며, 모든 DB 방언과 모든 SQL 문법을 완벽하게 지원하지 않을 수 있습니다. 생성된 ERD는 설계 검토와 문서화 보조 용도로 사용하는 것을 권장합니다.

서비스 운영자는 사전 공지 없이 기능을 변경하거나 서비스를 중단할 권리를 보유합니다.

광고

서비스 운영을 위해 광고가 표시될 수 있습니다. 광고 클릭은 사용자의 자유로운 선택이며, ERD 결과 열람을 위해 광고 클릭을 요구하지 않습니다.

지식재산권

AutoERD의 소프트웨어, 디자인, 문서는 운영자의 지식재산입니다. 사용자가 입력하고 생성한 ERD 다이어그램의 저작권은 사용자에게 있습니다.

면책 조항

서비스 이용 중 발생한 데이터 손실, 서비스 중단, ERD 생성 오류 등에 대해 운영자는 법이 허용하는 최대 범위 내에서 책임을 지지 않습니다.

약관 변경

운영자는 기능 개선, 정책 변경, 법령 준수를 위해 약관을 수정할 수 있습니다. 변경 시 서비스 내 공지를 통해 안내합니다.

문의

서비스 운영자 정보와 문의 채널은 정식 배포 시 추가됩니다.
