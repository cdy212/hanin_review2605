개인정보처리방침

시행일: 2026-05-21

AutoERD는 SQL DDL을 입력하면 ERD 다이어그램을 생성하는 무료 도구입니다. 입력한 DDL, 쿼리, DB명, 테이블명, 컬럼명 등 데이터베이스 정보는 기본적으로 별도 저장하지 않습니다.

수집하는 정보

현재 서비스는 회원가입 없이 사용할 수 있으며, 사용자가 입력한 SQL DDL을 서버 데이터베이스에 저장하지 않습니다. ERD 생성은 브라우저에서 즉시 처리됩니다.

서비스 접속 시 다음 정보가 자동으로 수집될 수 있습니다:

  • IP 주소 (Cloudflare Pages 자동 로그)
  • 브라우저 종류 및 버전
  • 접속 일시 및 페이지 URL

이 정보는 서비스 운영 및 보안 목적으로만 사용되며, 제3자에게 판매되지 않습니다.

광고와 쿠키

서비스 운영을 위해 Google AdSense 등 제3자 광고가 표시될 수 있습니다. 광고 제공자는 맞춤 광고, 빈도 제한, 부정 클릭 방지 등을 위해 쿠키 또는 유사 기술을 사용할 수 있습니다.

Google의 광고 관련 데이터 사용 방침은 Google 광고 정책에서 확인할 수 있습니다.

사용자가 입력하는 데이터

비밀번호, 접속 정보, 실제 개인정보, 민감한 운영 데이터는 입력하지 않는 것을 권장합니다. ERD 생성에는 CREATE TABLE 구조만 필요합니다.

제3자 서비스

본 서비스는 다음 제3자 서비스를 사용합니다:

  • Cloudflare Pages — 정적 사이트 호스팅
  • Google Fonts — 웹 폰트 제공
  • Google AdSense — 광고 서비스 (예정)

문의

서비스 운영자 정보와 문의 채널은 정식 배포 시 추가됩니다.
