💡 FOREIGN KEY 또는 REFERENCES 구문을 포함하면 관계선이 자동 생성됩니다
입력한 DDL, 쿼리, DB명, 테이블명 등 데이터베이스 정보는 기본적으로 별도 저장하지 않습니다. ERD 생성은 브라우저에서 즉시 처리되며, 회원가입 없이 안심하고 사용할 수 있습니다.
DB에서 DDL 추출하는 방법 보기

아래 명령으로 스키마만 추출한 뒤 생성된 SQL을 위 입력창에 붙여넣으면 됩니다. 비밀번호나 실제 데이터는 제외하고, CREATE TABLE 구조만 가져오는 방식을 권장합니다.

MySQL

mysqldump -u USER -p --no-data DB_NAME > schema.sql
SHOW CREATE TABLE table_name;

MariaDB

mariadb-dump -u USER -p --no-data DB_NAME > schema.sql
SHOW CREATE TABLE table_name;

PostgreSQL

pg_dump -U USER -d DB_NAME --schema-only --no-owner --no-privileges > schema.sql
pg_dump -U USER -d DB_NAME --schema-only --table=table_name > table_schema.sql

USER, DB_NAME, table_name은 본인 환경에 맞게 바꿔주세요. 외래키 관계선을 보려면 FOREIGN KEY 또는 REFERENCES 구문이 포함된 DDL을 붙여넣는 것이 좋습니다.
