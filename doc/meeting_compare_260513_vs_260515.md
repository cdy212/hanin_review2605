# 260513 1차 리뷰 vs 260515 한인회 의견 비교 검토

## 검토 목적

`260515_한인회.md`는 기존 `260513.md` 내용을 즉시 대체하는 확정안이 아니라, 한인회 의견을 반영한 추가 검토 자료이다.

따라서 dashboard, TODO, GitHub Issue에 전부 반영하기 전에 기존 260513 기준안과 다른 부분을 비교하고, 협의 또는 의사결정이 필요한 항목을 분리해야 한다.

## 결론

- 초기 개발 버전 자체는 “문제 없음”으로 확인됨.
- 다만 세부 화면, 회원가입 정보, 커뮤니티, 쿠폰 등록, 마이페이지, 권한 구조, MVP 범위가 더 구체화됨.
- 기존 260513의 “결정 필요 사안”보다 260515의 한인회 의견이 더 넓은 범위를 요구하므로, 바로 작업 Issue로 발행하지 말고 협의 대상 목록으로 관리해야 한다.

## 협의/의사결정 필요 항목

1. 하단 탭 명칭 및 구조
   - `제휴(쿠폰 Map)`을 유지할지, `쿠폰` 중심으로 단순화할지 결정.

2. 회원가입 단계
   - 1단계 간편가입, 2단계 기본정보, 3단계 선택정보, 4단계 약관동의 구조를 채택할지 결정.
   - 필수 항목: 이름, 휴대폰번호, 이메일, 거주 지역.
   - 선택 항목: 생년월일, 상세 주소, 직업/소속.

3. 권한 구조
   - 비회원 포함 여부.
   - 일반회원과 정회원의 차이.
   - 업체회원과 관리자 권한 범위.

4. 쿠폰 등록 및 승인 방식
   - 관리자만 등록할지, 업체가 직접 등록하고 관리자가 승인할지 결정.
   - 쿠폰 등록 페이지와 승인 상태 관리가 1차 MVP에 포함되는지 결정.

5. 커뮤니티 운영 정책
   - 게시판 카테고리.
   - 글쓰기 권한.
   - 이미지 첨부.
   - 댓글/대댓글.
   - 실명/닉네임/익명.
   - 신고 및 관리자 삭제 권한.
   - 금지 콘텐츠 정책.

6. 마이페이지 MVP 범위
   - 개인정보 수정.
   - 내가 쓴 글.
   - 내가 쓴 댓글.
   - 쿠폰 등록/제보.
   - 쿠폰 사용내역.
   - 1:1 문의.
   - 회원탈퇴.

7. MVP 1차/2차 범위
   - 260515 의견 기준 1차 범위가 기존 예상보다 커졌으므로 일정과 개발 범위 재산정 필요.

## 추천 처리 방식

- `260515_한인회.md`는 dashboard 회의록 탭에 표시한다.
- 단, TODO와 GitHub Issue에는 바로 전부 반영하지 않는다.
- 먼저 `협의 필요` 항목으로 분리하고, 승인자가 결정한 항목만 `pmo/state.json`과 `pmo/apply_plan.json`에 반영한다.
- GitHub Issue 발행은 승인 이후 진행한다.

## dashboard 반영 기준

- 즉시 반영:
  - 회의록 탭에 `260515_한인회.md` 표시.
  - Executive KPI 또는 상태 칩에 `한인회 의견 검토 필요` 표시 가능.

- 승인 전 반영 금지:
  - FRONT/BACK 작업 GitHub Issue 발행.
  - 기존 TODO 전면 교체.
  - MVP 범위 확정 표시.

- 승인 후 반영:
  - 확정된 상세 페이지 범위.
  - 확정된 회원가입 정보.
  - 확정된 권한 구조.
  - 확정된 쿠폰 등록/승인 방식.
  - 확정된 MVP 1차/2차 범위.
