# 00. 사전 필요 지식 (Prerequisites)
---

## 1. 🐙 버전 관리: Git (깃) 사용법
우리는 소스코드를 안전하게 관리하고 협업하기 위해 **Git**을 사용합니다.
- **`git clone`**: 처음 프로젝트 소스 코드를 내 PC로 다운로드 받을 때 사용합니다.
- **`git branch`**: 나만의 독립적인 작업 공간을 만듭니다. (예: `git checkout -b feature/login`)
- **`git add` & `git commit`**: 변경된 파일들을 장바구니에 담고(add), 영수증을 찍어 기록(commit)합니다.
- **`git push`**: 내 PC에 저장된 기록을 온라인(GitHub 등) 원격 저장소로 올려 팀원들과 공유합니다.
- **PR (Pull Request)**: "제가 이런 기능을 만들었는데, 메인 소스에 합쳐주세요!" 라고 요청하는 과정입니다. 관리자가 코드를 리뷰한 후 승인하면 실제 서버 코드에 반영됩니다.

---

## 2. 🧱 백엔드 기술 스택 (Backend)
서버와 데이터베이스 통신을 담당하는 보이지 않는 "엔진" 역할입니다. (`koreaTaiwanApi` 폴더)

- **Java 11**: 백엔드 프로그래밍 언어입니다. 11 버전을 내 PC에 설치해야 합니다.
- **Spring Boot 2.7**: 자바 서버를 빠르고 튼튼하게 만들어주는 가장 유명한 프레임워크입니다.
- **Spring Data JPA**: 복잡한 SQL(데이터베이스 언어)을 직접 쓰지 않고도, 자바 코드로 쉽게 DB를 다룰 수 있게 해주는 기술입니다.
- **JWT (JSON Web Token)**: 로그인한 유저가 '진짜 우리 유저가 맞는지' 증명하는 암호화된 출입증(토큰)입니다.
- **Maven**: 백엔드 실행에 필요한 외부 라이브러리(부품)들을 인터넷에서 자동으로 다운로드해주고, 프로젝트를 빌드(실행 파일 생성)해주는 도구입니다.

---

## 3. 📱 프론트엔드 기술 스택 (Frontend)
사용자가 직접 눈으로 보고 터치하는 화면(앱/웹)을 담당합니다. (`koreaTaiwan` 폴더)

- **React Native (React)**: 페이스북에서 만든 기술로, 자바스크립트(JavaScript) 하나만 알면 아이폰 앱과 안드로이드 앱을 동시에 만들 수 있습니다.
- **Expo**: React Native를 훨씬 쉽고 편하게 개발할 수 있도록 도와주는 마법 같은 도구 모음집입니다. 복잡한 앱 설정 없이도 빠르게 화면을 띄워볼 수 있습니다.
- **Node.js & npm**: 프론트엔드를 실행하기 위해 필요한 기본 환경과, 외부 라이브러리(패키지) 관리자입니다.

---

## 4. 🗄 데이터베이스 (DB) 및 접속 툴
회원 정보, 게시글 등 모든 데이터가 안전하게 보관되는 "창고"입니다.

- **데이터베이스 버전**: **MySQL 8.0**
- **무료 DB 접속 툴 (추천)**:
  명령어(검은 화면) 대신 마우스 클릭으로 쉽게 DB 데이터를 조회하고 수정할 수 있는 프로그램입니다.
  1. **DBeaver (디비버)**: 전 세계적으로 가장 많이 쓰이는 무료 DB 툴입니다. [DBeaver 공식 사이트](https://dbeaver.io/)에서 다운로드 후, MySQL 드라이버를 선택하여 접속합니다.
  2. **HeidiSQL (하이디SQL)**: 윈도우 환경에서 매우 가볍고 빠르게 동작하는 무료 툴입니다. [HeidiSQL 다운로드](https://www.heidisql.com/)

- **접속 방법 요약 (DBeaver 기준)**:
  1. DBeaver 실행 후 좌측 상단의 "새 연결(플러그 아이콘)" 클릭
  2. `MySQL` 선택
  3. Server Host (예: `localhost` 또는 `10.5.11.176`), Port (`13306`), Database, Username, Password 입력 후 `Test Connection` 클릭하여 연결 확인!
