# 02. 구체적인 작업 단위 및 비즈니스 플로우 (Workflow & Business)

이 문서는 KoreaTaiwan 서비스의 중요 비즈니스 시나리오가 화면(프론트엔드)부터 데이터 처리(백엔드)까지 어떻게 이어지는지 구체적인 플로우를 설명합니다.

---

## 1. 회원가입 및 로그인 플로우 (Authentication)
사용자가 앱에 접속하여 활동하기 위한 가장 첫 단계입니다.

- **비즈니스 로직**: 일반 회원은 소셜 로그인(구글, 카카오 등) 또는 자체 로그인을 통해 가입합니다. 가입 후 관리자(한인회)의 승인을 거치거나 후원/회비 납부를 확인받으면 **'정회원'** 또는 **'제휴회원'**으로 등급(Role)이 상승합니다. 탈퇴 시 1개월 유예 후 파기됩니다.
- **프론트엔드 작업 폴더 (`koreaTaiwan`)**:
  - 화면: `src/pages/Auth/` (로그인, 회원가입 화면)
  - API 호출 로직: `src/utils/api/auth.js`
- **백엔드 작업 폴더 (`koreaTaiwanApi`)**:
  - `controller/AuthController.java` : 아이디/비밀번호를 받아 인증 처리.
  - `service/JwtTokenProvider.java` : 인증 성공 시 JWT(Json Web Token)라는 보안 출입증을 발급.

## 2. 장소(업체) 등록 플로우 (Place Registration)
사용자에게 유용한 대만 현지의 업체(식당, 병원 등) 정보를 등록하는 기능입니다.

- **비즈니스 로직**: 프론트엔드 상단의 '업체 등록' 배너를 통해 등록 페이지로 진입합니다. 등록 폼에 업체명, 주소, 사진, 연락처를 입력하여 제출하면 대기 상태가 되며, 관리자가 확인 후 승인하면 최종적으로 지도(Region)와 목록에 노출됩니다.
- **프론트엔드 작업 폴더**:
  - 화면: `src/pages/Place/PlaceRegister.js`
- **백엔드 작업 폴더**:
  - `controller/PlaceController.java`
  - 데이터 저장: `Place`, `Category`, `Regions` 엔티티 활용.

## 3. 커뮤니티(게시판) 및 제재 플로우 (Community & Sanction)
사용자 간 소통 공간(구인구직 등) 및 악성 유저 차단 정책입니다.

- **비즈니스 로직**:
  - **구인구직 제한**: 정회원만 구인구직 게시판에 글을 쓸 수 있으며, 글 작성 횟수는 2주에 1회 등으로 제한(포인트 차감 방식)됩니다.
  - **신고 및 차단**: 특정 게시물이 사용자들로부터 3회 이상 신고를 받으면 프론트엔드에서 자동으로 숨김 처리(Blind)되며, 관리자가 최종 삭제합니다. 악성 유저는 3일/5일 차단 제재를 받으며, 접속 시 '소명 팝업'이 떠서 관리자에게 해명을 보낼 수 있습니다.
- **백엔드 작업 폴더**:
  - `controller/BoardController.java`, `service/SanctionService.java`
  - 제재 시 로그아웃 처리 필터: `security/JwtAuthenticationFilter.java`

## 4. 쿠폰 발행 및 사용 플로우 (Coupon Management)
업체가 발행하고 회원이 사용하는 혜택 시스템입니다.

- **비즈니스 로직**:
  - **발행**: '제휴회원(기업)' 등급 이상만 자신의 업체(Place)에 사용할 수 있는 쿠폰을 발행할 수 있습니다.
  - **사용**: 일반회원은 쿠폰 목록 구경만 가능하고, **'정회원'** 이상만 쿠폰을 다운로드 받고 사용할 수 있습니다.
- **백엔드 작업 폴더**:
  - `controller/CouponController.java` : 쿠폰 발급/사용 시 동시성(많은 사람이 동시에 쿠폰을 받을 때)을 고려한 Service 로직이 중요합니다.

---

> 💡 **코드 정보 요약**: 모든 API의 응답은 백엔드의 `ApiResponse` (또는 유사한 공통 DTO 클래스) 규격에 맞추어 `code`, `message`, `data` 구조로 반환되므로, 프론트 작업 시 해당 구조 파싱에 유의하세요.
