# 05. 사용자 기능 구체화 및 코드 구조 (User Features)

초보 개발자를 위한 일반 앱 이용자(User) 및 정회원 대상 서비스 프론트엔드/백엔드 구현 가이드입니다.

---

## 📱 사용자(앱 유저) 주요 기능 플로우

### 1. 업체 등록 요청 (일반/정회원 공통)
- **업무 플로우**: 메인 화면 상단 플로팅 배너 클릭 -> 혜택 안내 게시물 열람 -> 폼(업체명, 대표사진, 주소, 연락처) 작성 후 제출
- **프론트 작업 경로 (`koreaTaiwan`)**:
  - `src/pages/Home/Main.js` : 메인 화면 배너 UI 컴포넌트
  - `src/pages/Place/PlaceApply.js` : 등록 폼 화면 (React Hook Form 등 사용)
  - `src/utils/api/place.js` : Multipart/form-data(이미지 포함)로 백엔드에 POST 요청 전송
- **백엔드 작업 경로 (`koreaTaiwanApi`)**:
  - `controller/PlaceController.java`
  - *핵심 로직*: 이미지는 서버 스토리지(또는 S3)에 저장하고 URL 주소와 파일 메타 정보를 `file_upload` 테이블에 저장한 뒤, 폼 데이터는 `place` 테이블에 저장 (상태: 심사대기).

### 2. 구인구직 게시판 이용 (정회원 전용)
- **업무 플로우**: 일반 회원이 '구인구직' 글쓰기 버튼을 누르면 권한 부족 모달 알림이 뜹니다. 정회원일 경우 글쓰기 페이지로 넘어가며, 2주에 1회 제한 횟수를 체크합니다.
- **백엔드 로직 (`BoardController.java`)**:
  - 사용자 토큰(JWT)에서 Role을 추출하여 `ROLE_PREMIUM`(정회원) 여부 파악.
  - `user_posts` 테이블에서 해당 유저가 최근 14일 이내에 특정 카테고리(구인구직)에 작성한 이력이 있는지 `count` 쿼리로 조회 후 예외(Exception) 처리.

### 3. 쿠폰 발급 및 사용 내역
- **업무 플로우**:
  - 기업회원이 발행한 쿠폰 목록 페이지 진입 (`src/pages/Coupon/CouponList.js`)
  - '다운로드' 버튼 클릭 시, 정회원 여부 체크 후 `coupon_user` 테이블에 내역 Insert.
  - 내 쿠폰함에서 사용하려는 매장 직원에게 보여주고 '사용하기' 버튼 클릭.
- **백엔드 로직 (`CouponController.java`)**:
  - *핵심 로직*: `coupon_user` 테이블의 `is_used` 값을 `true`로 바꾸고 `use_date`를 현재 시간으로 업데이트합니다. 그와 동시에 히스토리 추적을 위해 `coupon_user_history` 테이블에 로그 레코드를 하나 생성(Insert)합니다.

### 4. 제재(차단) 소명하기
- **업무 플로우**: 관리자에 의해 차단(블락) 당한 후 로그인 시도 시, "소명 알림 팝업"이 뜹니다. 해당 팝업에서 바로 사유를 적어 제출할 수 있습니다.
- **백엔드 로직**: 차단된 계정이라도 '소명 API'(`/api/v1/user/appeal`) 만큼은 호출할 수 있도록 Spring Security Filter에서 허용(PermitAll 또는 별도 예외처리)해 주어야 합니다.

🎉 **문서 고도화 완료!**
1~5편의 가이드를 통해 초보 개발자도 프론트엔드의 화면(Page)이 어떻게 백엔드의 Controller 및 DB 테이블까지 맞물려 돌아가는지 쉽게 파악할 수 있습니다.
코딩 중 막히는 부분이 있다면, 각 단계별로 명시된 폴더 경로로 이동하여 관련 코드를 직접 열어보시면 큰 도움이 될 것입니다.
