한인회 정책 확정

1. 회원

  • 1.1 인증
    • 일반 회원 → 정회원, 제휴회원 인증 방식
    • a. 휴대폰 인증 - 건당 비용 발생
    • b. ARC 혹은 신분증 인증 - 인증 후 즉시 파기 혹은 보관 여부 체크 필요
    • * 쿠폰 및 인증의 경우 별도 QR은 사용하지 않으며 문자열 기반 쿠폰을 제휴사 PIN 인증 방식으로 진행
  • 1.2 개인정보
    • 수집 범위 (https://kr.happytuk.tw/mypage/edit)
      • 이메일, 휴대폰, 주소, 생년월일, 위치정보(한인맵)
    • 파기 시점: 정책 정의 필요

2. 업체등록

  • 2.1 등록 플로우 (https://kr.happytuk.tw/main)
    메인 상단 플로팅 배너 혹은 상단 배너 '업체 등록' 버튼 노출
    →업체 등록 혜택 및 정책 내용 등 기록된 게시물 이동
    →업체 등록 요청 시 [업체명, 대표사진, 업체주소, 연락처] 등 기입
    →관리자 확인/승인 절차 후 업체 등록 완료

3. 커뮤니티

  • URL: https://kr.happytuk.tw/community
  • 카테고리별 작성 권한
    • 자유게시판 - 정회원
    • 구인구직 - 관리자
    • 중고장터 - 정회원
    • 공지사항 - 정회원
    • 뉴스 - 시스템 자동
  • 제재
    • 게시판: 신고 발생 시 자동 숨김 처리 → 관리자 확인 후 숨김/삭제 처리
    • 사용자: 제재 필요한 사용자의 경우 관리자 수동 처리 및 로그인 불가
