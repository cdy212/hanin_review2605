# 회의 최종 정책 확정 내용 (26.06.30)

## 중요 안건
- 웹 혹은 안드로이드 포함 빠르게 오픈 가능한 스펙부터 소프트 런칭. 운영 개선 후 기능 안정화 및 추가 어플 오픈 검토.
- 포인트 정책 (2차 검토)
  - 관리자는 수동으로 포인트를 지급.
  - 포인트는 특정 권한('구인구직 등록' 등)을 사용하는데 소비.
  - [필요] 소비 기록 로그 및 차감 방식에 대한 개발 정책 설정 필요.
- 오픈 전 개발 완료 사항에 대한 피드백 후 테스트 진행.
- 관리자 페이지 링크 공유 후 피드백 반영.

## 상세 정책 확정 내용

### 1. 회원
- **인증 방식:** 일반 회원 → 정회원, 제휴회원 인증. (한인회비 내신 분 / 후원하신 분 / 기타)
- **한인회 정의:** 수동 관리자 인증 처리.
- **개인정보 수집 항목:**
  - **일반회원:** 이메일, 소셜계정 Key (필수) / 생년월일, 핸드폰, 주소 (선택)
  - **정회원:** 이름, 소속, 직위, 연락처, 이메일
  - **기업회원:** 회사명, 대표자명, 회사 주소, 연락처, 이메일
- **개인정보 탈퇴 시:** 1달 후 파기.

### 2. 업체 등록
- **등록 플로우:** https://kr.happytuk.tw/main
  - 메인 상단 플로팅 배너 혹은 상단 배너 '업체 등록' 버튼 노출.
  - 업체 등록 혜택 및 정책 내용 등이 기록된 게시물로 이동.
  - 업체 등록 요청 시 기입 항목: **업체명, 대표사진, 업체주소, 연락처**.
  - 관리자 확인/승인 절차 후 업체 등록 완료.

### 3. 커뮤니티
- **URL:** https://kr.happytuk.tw/community
- **구인구직 (정회원):** 게시물 작성 횟수 제한 설정 (예: 2주에 1번).
- **제재 정책:**
  - [게시판] 3회 신고 발생 시 자동 숨김 처리 → 관리자 확인 후 숨김/삭제 처리.
  - [사용자] 제재 필요 시 관리자 수동 처리 및 로그인 불가.
  - 제재 등급을 통해 3일 차단 / 5일 차단 방식으로 제재.
  - 제재 후 로그아웃 처리 → 로그인 시 '소명 알림 팝업' 노출 (바로 작성 가능) → 관리자가 소명 내용 검토 후 처리.

### 4. 쿠폰
- 쿠폰 발행: **기업회원 이상**만 가능.
- 쿠폰 사용: **정회원 이상**만 가능. (단, 일반회원도 쿠폰 목록은 볼 수 있음)
- 사용 이력 리스트 확인 및 **외부 파일 다운로드** 기능 추가.
