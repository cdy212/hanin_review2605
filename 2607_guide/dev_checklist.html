# 항목 정책 답변
1
회원 인증 방식
이메일 / 휴대폰 / 회원명부 / 관리자 승인 / ARC 등

정회원 / 기업회원 → 한인회 관리자 수기 인증

  • 일반 회원 가입 후, 관리자가 수동으로 정회원/제휴회원 인증 처리.
  • 인증 대상: 한인회비 납부자 / 후원자 / 기타 (한인회 내부 기준 적용)
  • 인증에 필요한 내부 기준 정보 및 확인 항목은 추가 정의 필요.
2
ARC / 신분증 자료 보관
인증 후 삭제할지, 보관할지 확인 필요

보관하지 않음. 인증 후 서버에 저장하지 않습니다.
3
업체 등록 방식
한인회 직접 등록 / 업체 신청 / 한인회 승인 후 등록

업체 직접 신청 → 한인회 관리자 승인 후 등록

  • 메인 상단 플로팅 배너 '업체 등록' 버튼 노출 → 혜택/정책 게시물로 이동.
  • 기입 항목: 업체명대표사진업체주소연락처첨부파일
  • 관리자 확인/승인 후 등록 완료. (kr.happytuk.tw/main)
4
할인 QR 이용 방식
QR 스캔 / 기록 저장 / 회원정보 범위 확인 필요

QR 보류 → PIN 번호 방식으로 대체

  • 업체가 쿠폰 등록 → 사용자 개별 다운로드 → 업체에 PIN 입력하여 사용 처리.
  • 사용자는 쿠폰 1인 1개만 발급. 발급/사용 이력 확인 가능.
  • 발행권한: 기업회원 이상 / 사용권한: 정회원 이상 (일반회원은 목록만 조회)
  • 사용 이력 엑셀 다운로드 기능 추가 예정.
5
업체가 확인 가능한 회원 정보
유효 회원 여부만 표시할지 확인 필요

사용자가 쿠폰을 업체에 직접 공유 → 업체가 PIN 입력으로 사용 처리.

  • 별도 회원 정보 확인 없음. 업체는 회원 개인정보에 접근하지 않습니다.
6
위치정보 사용 여부
주변 업체 찾기 기능에서 위치정보 사용 여부

위치 정보 사용. 주변 업체 찾기 기능에서 사용자 위치정보를 활용합니다.
7
자유게시판 운영 방식
작성 권한, 신고, 삭제, 정지 처리 방식
  • 작성권한: 정회원 이상 / 구인구직: 2주에 1회 제한
  • 신고: 3회 누적 시 자동 숨김 → 관리자 확인 후 숨김/삭제 처리.
  • 사용자 제재: 관리자 수동 처리, 제재 등급 3일/5일 차단.
  • 제재 후 로그아웃 → 재로그인 시 '소명 알림 팝업' 노출 → 관리자 검토 후 최종 처리.
8
개인정보 수집 및 보관
수집 항목, 보관 기간, 삭제 방식
  • 일반 필수: 이메일소셜계정 Key
  • 일반 선택: 생년월일,핸드폰주소

  • 기업회원: 회사명대표자명회사 주소연락처이메일
  • 삭제: 탈퇴 신청 후 30일 경과된 사용자에 한하여 삭제 처리.

# 2차 확인 항목 확인 세부 내용 (PDF 원문 그대로 노출) 현재 현황 및 정책 답변 (순번 정렬 / 정책결정 필요항목 음영)
1
푸시 기능의 「소식」의 범위
  • 한인회 공지, 행사 및 서비스 알림만 포함하는지 확인 필요
  • 업체 혜택, 쿠폰, 제휴 행사 등 홍보성 정보도 포함하는지 확인 필요
  1. 앱 내 기본 서비스 알림(공지사항, 시스템 안내) 기능은 탑재되어 있습니다.
  2. 정책 결정 필요 알림 발송 시 공지사항 외에 제휴업체 할인쿠폰 및 홍보성 알림도 함께 발송할지 여부 결정이 필요합니다.
  3. 홍보성 알림을 발송하는 경우, 회원가입 화면이나 설정에서 '마케팅 정보 수신 동의' 선택 항목을 추가로 동의받아야 합니다.
2
쿠폰 이용 기록 엑셀 열람 범위
  • 관리자, 쿠폰 발행 기업회원 또는 양쪽 모두 열람 가능한지 확인 필요
  • 역할별 열람 가능 범위 확인 필요
  • 다운로드 파일에 실제 포함되는 항목 확인 필요
  1. 제휴업체와 관리자가 쿠폰 발급 및 사용 내역을 화면에서 확인하는 기능은 준비되어 있습니다.
  2. 정책 결정 필요 쿠폰 사용 내역을 엑셀 파일로 다운로드할 때 [관리자만 다운로드 가능 / 제휴업체도 자사 쿠폰건 다운로드 가능] 중 권한 범위를 확정해야 합니다.
  3. 정책 결정 필요 엑셀 다운로드 파일에 사용자 개인정보(이름, 연락처)를 그대로 포함할지, 아니면 개인정보 보호를 위해 마스킹(예: 홍*길, 010-****-1234) 처리할지 결정해야 합니다.
3
회원 탈퇴 방식
  • 정식 APP 의 탈퇴 신청 경로 또는 접수 방식 확인 필요
  • 탈퇴 후 30 일 보관 기간의 기산 시점 확인 필요
  • 30 일 경과 후 계속 보관되는 자료(쿠폰 이용기록등) 확인 필요
    • 기능 제공 시 확인
    • 탈퇴 신청 철회 기능 제공 여부 확인 필요
    • 신청 후 30 일 동안 앱 열람 또는 이용이 가능한지 확인 필요
  1. 앱의 설정 메뉴에서 사용자가 직접 탈퇴 동의 후 즉시 처리되는 기능이 구현되어 있습니다.
  2. 정책 결정 필요 탈퇴 신청 즉시 계정을 파기하는 기존 방식 대신 '30일간 탈퇴 유예기간(신청 철회 및 보류 기간)'을 부여할 것인지 결정이 필요합니다.
  3. 정책 결정 필요 30일 유예기간 동안 사용자가 앱에 다시 로그인하여 서비스를 정상 이용(철회)할 수 있게 할지, 또는 로그인을 차단할지 결정이 필요합니다.
  4. 탈퇴가 완료되더라도 관계 법령(거래 및 쿠폰 사용 기록 등)에 따라 보관 의무가 있는 자료는 30일 경과 후에도 별도 보관됩니다.
4
수집 자료 및 시스템 기록
  • 시스템에서 자동 생성하거나 저장하는 자료 확인 필요
    • 예: IP 주소, 기기 모델 또는 식별정보, 운영체제, 로그인 및 이용 기록, 오류 기록, 보안 로그 등
  • 회원 인증 신청 시 실제 첨부파일 항목에 업로드하도록 요구하는 자료 유형 확인 필요
    • 예) ARC 사진, 사업자 또는 업체 등록을 증명할 수 있는 서류 등
  1. 서비스 접속 시 기기 종류, IP 주소, 로그인 시간 등 기본 시스템 기록은 서비스 보안 및 운영 목적으로 자동 기록됩니다.
  2. 제휴업체 신청 및 회원 인증 시 증빙 서류(사진, 첨부파일)를 등록하는 기능이 구현되어 있습니다.
  3. 정책 결정 필요 회원/업체 인증 시 제출받는 증빙 서류(ARC 신분증 사진, 사업자등록증 등)를 확인 후 서버에 보관할지, 확인 즉시 안전하게 파기할지 방침 확정이 필요합니다. (권장: 확인 후 즉시 파기)
5
개인정보 보관 기간
  • 쿠폰 이용 기록, 위반 기록, 로그인 및 보안 기록, 고객문의 기록, 기업회원 및 업체 심사 기록 등의 보관 기간 확인 필요
    • 예) 회원 탈퇴 처리 완료 시까지, 서비스 운영 종료 시까지 또는 별도 보관 기간
  1. 회원의 일반 개인정보는 회원 탈퇴 처리가 완료되는 즉시 지체 없이 삭제됩니다.
  2. 정책 결정 필요 서비스 분쟁 예방 및 법령 준수를 위해 쿠폰 이용 기록(5년), 로그인/접속 기록(3개월), 제재/위반 기록, 고객문의 기록의 구체적인 보관 기간을 약관에 명시해야 합니다.
6
위치정보 처리 방식
  • 「주변 업체 찾기」 기능 이용 시에만 실시간으로 처리하는지 확인 필요
  • 위치정보를 서버로 전송하거나 저장하는 경우 보관 기간 확인 필요
  1. 사용자가 지도 화면에서 「주변 업체 찾기」를 클릭하거나 내 위치를 조회할 때만 현재 위치(위도, 경도)를 실시간으로 사용합니다.
  2. 위치 정보는 서버로 전송되거나 저장되지 않으며, 화면에서 거리 계산용으로 순간 사용된 후 즉시 삭제됩니다. (추가 정책 결정 필요 항목 없음)
7
제 3 자 또는 수탁업체 서비스 이용
  • 정식 출시 후 제 3 자 또는 수탁 서비스를 통해 실제 수집, 제공 또는 처리되는 회원정보 확인 필요
    • 예: 소셜 로그인, 푸시 알림, 분석 도구, 오류 추적 도구 등
  • 푸시 알림 서비스에서 실제 처리하는 자료 확인 필요
    • 예: 푸시 토큰, 운영체제, 앱 버전, 기기 관련 정보 등
  • 분석 또는 오류 추적 도구 사용 여부와 실제 수집 자료 확인 필요
  • 해당 자료가 대만 외 국가 또는 지역에서 처리되는지 확인 필요
  1. 로그인 편의를 위해 소셜 로그인(카카오, 라인, 구글, 네이버, 애플) 연동을 사용하며, 소셜 식별번호 및 이메일 정보를 처리합니다.
  2. 알림을 보내기 위해 알림 전송 전문 서비스(구글/애플 알림 서버)로 기기 구분값(토큰)과 앱 버전 정보가 전달됩니다.
  3. 정책 결정 필요 소셜 로그인 및 알림 서비스 이용 과정에서 데이터가 외부 서버(한국, 미국 등)에서 처리되므로, '개인정보 처리위탁 및 국외 이전' 안내 문구를 약관에 수록하는 것을 결정해야 합니다.

2 쿠폰 엑셀 다운로드 다운로드 권한(관리자 전용 vs 제휴업체 포함) 및 회원 이름/연락처 마스킹 여부 결정
3 회원 탈퇴 처리 즉시 파기 대신 30일 탈퇴 유예기간/철회 기능 제공 여부 및 유예기간 내 앱 로그인 가능 여부 결정
4 증빙 서류 보관 회원/업체 인증 시 제출받은 신분증/사업자등록증 사진의 확인 후 즉시 파기 방침 확정
5 정보 보관 기간 쿠폰 사용 기록(5년), 접속 기록(3개월) 등 항목별 보관 기간 약관 수록 확정
7 외부 서비스 위탁 소셜로그인, 알림 서비스 이용에 따른 개인정보 처리위탁 및 국외 이전 약관 명시 확정
